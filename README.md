# 전주 심야 풍류록 (全州 深夜 風流錄 · Jeonju Midnight Pungryu-rok)

> **토요일 밤 7시, 문 닫은 서점이 당신만을 위해 열립니다.**  
> 완판본문화관의 골든아워부터 1952년 삼양다방의 한식 다이닝 & 전통주 페어링, 그리고 심야 에이커북스토어에서의 8면 병풍형 아코디언 Zine 살롱까지 이어지는 전주 원도심 프리미엄 로컬 투어 프로모션 웹사이트.

---

## 🌟 주요 특징 (Features)

- **Awwwards급 비주얼 & 인터랙션**:
  - 부드러운 파스텔 메시 블롭 애니메이션 및 미세 필름 그레인 텍스처
  - Lenis 기반 스무스 스크롤링 & Framer Motion 마이크로 인터랙션
  - 고유한 인자/낙관(Seal Stamp), 마퀴(Marquee) 티커, 맞춤형 잉크 커서
- **8면 병풍형 아코디언 북 (Accordion Zine)**:
  - 완판본 세로 타이틀 표제 박스 & 목판 검인 낙관
  - **4축 테이스팅 스타 레이팅**: 단맛, 산미, 바디감, 여운을 인터랙티브하게 별점으로 기록 (★ 1~5점)
  - 1952 삼양다방 주안상 3코스 페어링 메뉴 카드 & 고운바탕/나눔명조/노토세리프 서체 적용
  - 3D 병풍 접힘 모드, 전면 펼침(Spread) 모드, 면별 고해상도 집중(Focus) 모드 지원
  - 8면 단독 절취형 엽서(Postcard) — 실제 30일 뒤 우편 발송 콘셉트
- **스토리텔링 코스 (15:00 ~ 20:30)**:
  - 데스크톱 스크롤스티키 타임라인 & 일몰에서 심야로 변화하는 조명 무드
  - 골든아워 완판본문화관 → 삼양다방 만찬 → 심야 에이커북스토어
- **모던 문인 한복 철학**:
  - 금박/원색 대신 먹색, 옥색, 생성색, 감색의 4색 실크 스와치
- **3단계 보딩패스 티켓 & 모달 예약**:
  - 동행 2인 이상 '벗님 패스' 인당 5,000원 자동 할인
  - 다가오는 토요일 일정 선택 및 무알코올 페어링 옵션 제공

## 🛠 기술 스택 (Tech Stack)

- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, 3D Transforms)
- **Typography**: Gowun Batang, Nanum Myeongjo, Noto Serif KR, Instrument Serif, Pretendard
- **Animation**: Framer Motion 11
- **Smooth Scroll**: Lenis
- **Deployment**: GitHub Actions + GitHub Pages
